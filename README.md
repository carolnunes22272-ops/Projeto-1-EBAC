# Projeto 1 — Analista de Dados (EBAC)

Repositório criado para a entrega do **Projeto 1** do módulo de Analista de Dados da [EBAC](https://lms.ebaconline.com.br/dashboard).

---

## 🐍 Explicação do Código em Python (`analise.py`)
O código desenvolvido em Python simula um fluxo básico de tratamento e análise de dados de vendas:
1. **Estrutura de Dados:** Utiliza uma lista de dicionários para representar os produtos, suas categorias, preços e quantidades vendidas.
2. **Processamento:** Percorre os dados aplicando uma operação matemática simples para calcular o faturamento total de cada item e o faturamento geral da loja.
3. **Exibição:** Mostra os resultados processados diretamente no terminal de forma organizada.

---
